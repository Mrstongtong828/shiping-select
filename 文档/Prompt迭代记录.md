# Prompt 迭代记录

当前 Prompt 文件：`prompts/eval_template.txt`

本记录用于证明 LLM 评估不是一次性拍脑袋生成，而是根据真实误判和项目验收指标持续调整。

## V1：基础 JSON 评分版

目标：让模型对视频输出固定 JSON 字段，便于程序写入 CSV 和 Markdown。

字段：

- `relevance`
- `depth`
- `clarity`
- `has_math`
- `has_code`
- `audience`
- `recommend`
- `reason`

特点：

- 明确要求只输出合法 JSON。
- 给出 relevance、depth、clarity 的 0-10 分解释。
- 要求 `audience` 只能在科普、本科入门、本科进阶、研究生中选择。

发现的问题：

- 模型容易因为无字幕而直接判定 `recommend=no`。
- 对短视频作为“科普入门材料”的价值识别不足。
- `reason` 偶尔会写得过长，不利于 CSV 人工复核。

## V2：无字幕谨慎评估版

触发原因：YouTube transcript 在当前网络出口下出现访问限制，部分 B 站公开视频也没有可用公开字幕。如果无字幕一律不推荐，会导致候选覆盖不足。

修改点：

- 明确“无字幕不等于不能推荐”。
- 允许模型结合标题、简介、播放量、点赞数和时长进行谨慎判断。
- 对无字幕视频降低深度和清晰度判断的置信度，但不直接一票否决。

效果：

- 历史人工对照 10 条样本中，系统与人工一致 8 条，一致率 80%，达到任务书 ≥70% 要求。
- 仍有 2 条人工认为可推荐而系统判为不推荐，主要集中在短视频或无字幕视频。

## V3：短视频入门资源识别版

触发原因：人工对照中发现“一分钟了解主成分分析”这类短视频不适合作为完整课程资源，但可以作为课前导入或概念科普。

修改点：

- 将短视频从“核心教学资源”中区分出来。
- 如果短视频主题明确、内容聚焦，可推荐为“科普”层级。
- 要求在 `reason` 中说明“适合作为快速了解，不适合作为完整学习材料”。

当前 Prompt 中的体现：

- “短视频可以作为科普入门材料，但需要在 reason 中说明局限。”
- “如果字幕缺失，可以结合标题、简介和统计信息给出谨慎判断，不要因为无字幕直接否定。”

## 下一轮验证计划

配置 `.env` 后重新运行：

```powershell
python main.py --topic "PCA 主成分分析" --platform bilibili,youtube --max 30
```

检查项：

- JSON 解析失败数是否 ≤2。
- 评估成功率是否 ≥90%。
- 随机抽样 10 条后，一致率是否仍 ≥70%。
- 无字幕视频是否仍然过度保守。
