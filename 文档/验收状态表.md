## 自动自检

根目录提供离线自检脚本：

```powershell
python scripts\acceptance_check.py
```

自检脚本会检查核心文件、中文乱码、Prompt 字段、README 可复现性、文档材料、文档提交清单、输出样例 CSV/JSON/Markdown/log、CLI 功能入口、缓存、缓存自检工具、ASR、ASR 环境自检工具、抖音整合、抖音降级说明、Streamlit UI、Streamlit UI 自检工具、终验前置检查工具、终验复跑编排工具、提交样例刷新工具、提交包工具、终验审计报告工具、终验审计报告文档、演示录屏生成工具、忽略规则、环境模板、仓库密钥扫描和依赖覆盖。默认模式下，真实 `.env` 和双平台完整输出会作为 `WARN` 提醒；正式终验前可以运行严格模式：

```powershell
python scripts\acceptance_check.py --strict
```

严格模式会把这些人工/外部依赖项视为失败，适合提交前最终确认。

生成汇总审计报告：

```powershell
python scripts\final_audit.py
```

生成演示说明视频：

```powershell
python scripts\generate_demo_recording.py
```

预览完整终验复跑：

```powershell
python scripts\run_final_acceptance.py --dry-run
```

答辩 PPT 已生成在 `答辩/答辩PPT.pptx`。如需根据 Markdown 草稿重新生成：

```powershell
python scripts\generate_pptx.py
```
