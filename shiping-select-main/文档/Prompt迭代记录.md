## 版本记录

### V1：基础结构化评分版

**目标**

让大模型根据学习主题、视频标题、简介、字幕和基础统计信息，输出固定 JSON 字段。

**字段**

- `relevance`
- `depth`
- `clarity`
- `has_math`
- `has_code`
- `audience`
- `recommend`
- `reason`

**当前特点**

- 明确要求只输出合法 JSON。
- 对 `relevance`、`depth`、`clarity` 给出评分解释。
- 允许字幕缺失时基于标题、简介和统计信息谨慎判断。

**待观察问题**

- 无字幕视频是否容易被过度推荐。
- `audience` 是否能稳定区分“科普 / 本科入门 / 本科进阶 / 研究生”。
- `has_math` 和 `has_code` 是否受标题关键词误导。

### V2：无字幕视频分层评估版

**触发原因**

完整运行后发现 YouTube transcript 受网络出口限制，15 条 YouTube 结果均未拿到字幕。系统仍能根据标题、简介和统计信息完成评估，但对无字幕视频整体偏保守。

**修改内容**

计划在 Prompt 中补充：

- 无字幕不等于不能推荐，应结合标题、简介、播放量、点赞数和视频时长进行谨慎判断。
- 对无字幕视频降低对“深度”和“清晰度”的置信度，但不要直接将 `recommend` 判为 `no`。
- 如果视频适合快速建立概念，即使较短，也可推荐为“科普”或“本科入门”层级。

**效果**

人工抽样 10 条后，系统与人工一致 8 条，一致率 80%，达到项目书 ≥70% 的要求。

### V3：短视频入门资源识别版

**触发原因**

人工对照中发现，系统把“一分钟了解主成分分析”判为不推荐，但人工认为这类短视频可作为初学者快速建立概念的材料。

**修改内容**

计划在 Prompt 中补充：

- 3 分钟以内的视频通常不适合作为“核心教学资源”。
- 但如果标题明确、主题高度相关、用于建立初步概念，可以推荐为“科普”层级。
- `reason` 中需要说明“适合作为快速了解/课前导入，不适合作为完整学习材料”。

**效果**

待下一轮评估验证。
