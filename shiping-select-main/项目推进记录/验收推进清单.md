# 验收推进清单

本文档对照《视频学习资源智能筛选系统_项目实施方案书_v2.docx》，记录当前项目距离终验收还差哪些材料。

## 已具备

- B 站搜索与元数据抓取。
- B 站字幕抓取逻辑。
- YouTube 搜索与 transcript 抓取逻辑。
- 统一 `VideoRecord` 数据模型。
- LLM 结构化评估模块。
- CSV / JSON / Markdown / 运行日志导出。
- 基础测试：`python -m pytest` 当前通过 3 个测试。
- B 站 PCA 最小样例输出：`results/PCA_主成分分析.*`。

## 推荐执行顺序

1. 创建 `.env` 并填入 `YOUTUBE_API_KEY`、`OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_MODEL`。
2. 运行完整流程：

```powershell
.\.venv\Scripts\python.exe main.py --topic "PCA 主成分分析" --platform bilibili,youtube --max 30
```

3. 检查 `results/PCA_主成分分析.csv` 中评估字段是否完整。
4. 选取 10 条结果制作人工对照评估表。
5. 根据结果优化 Prompt，并记录版本。
6. 生成最终 README、反思报告、Prompt 迭代记录和答辩材料。
