# 答辩大纲

## 1. 项目背景

- 教师和学生需要在大量公开视频中快速筛选适合学习的资源。
- 手工筛选效率低、覆盖窄、主观性强。
- 本项目用工程流水线解决“学习资源筛选”问题。

## 2. 系统目标

- 输入学习主题。
- 从 B 站和 YouTube 检索候选视频。
- 抓取元数据和字幕。
- 调用 LLM 做结构化教学价值评估。
- 导出 CSV、JSON、Markdown 和运行日志。

## 3. 系统架构

- `main.py`：命令行主入口。
- `src/search_bilibili.py`：B 站搜索与字幕。
- `src/search_youtube.py`：YouTube 搜索与字幕。
- `src/evaluate.py`：LLM JSON 评估。
- `src/exporters.py`：结果导出。
- `src/cache_utils.py`：缓存层。
- `app.py`：Streamlit UI。

## 4. 核心演示

建议现场演示命令：

```powershell
python main.py --topic "PCA 主成分分析" --platform bilibili --max 5 --skip-evaluate
python main.py --topic "佛山中考数学" --platform douyin --max 3 --skip-evaluate
streamlit run app.py
```

如果已配置 `.env`，再演示：

```powershell
python main.py --topic "PCA 主成分分析" --platform bilibili,youtube --max 30
```

## 5. 验收结果

- 测试：`pytest` 当前 44 passed。
- 静态检查：`ruff` 和 `black --check` 通过。
- 人工对照：10 条样本一致率 80%，达到 ≥70%。
- 输出：可生成 CSV、JSON、Markdown 和 run log。

## 6. 风险与反思

- 字幕成功率受平台和网络出口影响。
- YouTube transcript API 版本变化需要持续跟进。
- 抖音平台工程代价高，适合作为加分项和对比实验。
- 可运行不等于可验收，必须有文档、测试和真实样例。
