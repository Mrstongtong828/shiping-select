# 演示录屏说明

当前已生成 `答辩/演示录屏.mp4`。该文件由脚本自动生成，用于在提交材料中快速说明项目已验证能力、离线验收结果和仍需真实 API Key 复跑的边界。

## 重新生成

如需重新生成视频，在项目根目录运行：

```powershell
python scripts\generate_demo_recording.py
```

脚本会调用本机 `ffmpeg`，输出路径为：

```text
答辩/演示录屏.mp4
```

## 真实操作录屏脚本

如果老师要求真实浏览器或终端操作录屏，可按以下顺序重新录制并覆盖 `答辩/演示录屏.mp4`：

1. 展示根目录结构和 `goal.md`。
2. 运行测试：

```powershell
python -m pytest
python -m ruff check .
python -m black --check .
```

3. 运行 B 站小样本：

```powershell
python main.py --topic "PCA 主成分分析" --platform bilibili --max 5 --skip-evaluate
```

4. 展示 `results/PCA_主成分分析.csv` 和 `results/PCA_主成分分析.md`。
5. 运行抖音参考数据流程：

```powershell
python main.py --topic "佛山中考数学" --platform douyin --max 3 --skip-evaluate
```

6. 启动 UI：

```powershell
streamlit run app.py
```

7. 如果已经配置 `.env`，演示双平台完整流程：

```powershell
python main.py --topic "PCA 主成分分析" --platform bilibili,youtube --max 30
```

## 边界说明

当前自动生成视频不会伪造 YouTube 搜索或 LLM 调用结果。真实双平台 30 条完整输出仍需要在 `.env` 中配置 `YOUTUBE_API_KEY`、`OPENAI_API_KEY`、`OPENAI_BASE_URL` 和 `OPENAI_MODEL` 后复跑，并通过 `scripts/refresh_submission_samples.py` 刷新提交样例。
